# Minecraft Texture: KBW Duck Hoodie

KBW Duck Hoodie is a Minecraft texture skin for Bedrock Edition featuring black messy hair, a green hoodie, a yellow duck graphic on the front, blue pants, black shoes, and black “KBW” lettering with a diamond sword and pickaxe design on the back.

## Install

1. Download `assets/textures/kbw_duck_hoodie_skin.svg`.
2. Export or convert the SVG to a 64x64 PNG image.
3. Open Minecraft Bedrock Edition.
4. Go to Dressing Room.
5. Select Create Character or Classic Skin.
6. Choose Import and select the converted PNG file.
7. Apply the imported skin.

## Use

1. Equip the skin from the Dressing Room.
2. Use it in single-player worlds, multiplayer worlds, or supported servers.
3. View the yellow duck graphic on the front of the hoodie.
4. View the “KBW” lettering, diamond sword, and diamond pickaxe design on the back.
